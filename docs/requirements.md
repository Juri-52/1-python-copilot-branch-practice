# 在庫不足一覧の要件
メニューを「在庫不足の商品」に絞って表示できるようにすること

## 目的
在庫が少ない商品をまとめて確認したい

## 対象になる条件と対象にならない条件
stockが3未満(0含む)の商品を「在庫不足の商品」として定義する

## 表示する内容と順番
通常の商品一覧の並び順・表示形式は維持すること

## 対象がない場合
日本語でその旨を表示すること

## 確認する入力と期待する結果
stockが0,1,2の商品のみ表示されること（3の商品は表示されないこと）
在庫不足の商品とされるものが存在しない場合はそのことが日本語で表示されること
